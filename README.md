# wealth-hub

個人向けの家計・資産管理ダッシュボードです。

## 現在の状態

初期段階の**サンプルデータ専用デモ**です。銀行・クレジットカード・証券会社との接続、ログイン、データ永続化は未実装です。画面に表示される金額はすべて架空の数値です。

## ローカル実行

Node.js 22 以降が必要です。

```sh
npm run dev
# http://localhost:4173
npm test
```

外部パッケージのインストールは不要です。

## 想定アーキテクチャ（未構築）

- フロントエンド: S3 + CloudFront (HTTPS)
- 認証: Amazon Cognito (Authorization Code + PKCE)
- API: API Gateway + Lambda (JWT 検証、ユーザー単位の認可)
- DB: DynamoDB (ユーザー単位のパーティション分離)
- 集約: 明示的に許可されたデータソースのみ。公式APIと利用規約を個別に検証すること

ブラウザーから DynamoDB を直接呼び出さず、AWSアクセスキーも配布しません。

## セキュリティ

- このリポジトリは Public です。実際の家計・口座・カード・取引データをコミットしないこと
- .env、AWS認証情報、秘密鍵、銀行APIトークンなどはコミットしないこと
- 本番リリース前に Cognito、API認可、監査ログ、暗号化、バックアップ、CSP、脆弱性診断を確認すること
- デモでは localStorage / Cookie / 外部通信へのデータ保存は行いません
- 現段階では**本番利用不可**です
