# 金額計算の契約

関連: #12。現段階は合成データ専用のデモであり、実データは扱わない。

## 入力

金額は整数円を表すJavaScriptの安全整数とする。`NaN`、無限大、小数、安全整数範囲外は `TypeError` で拒否する。文字列からの暗黙変換、丸め、不正レコードの黙った除外は行わない。ゼロ円と負の残高は許可し、負のゼロは通常のゼロへ正規化する。

取引は符号で分類する前に検証する。正は収入、負は支出、ゼロはどちらにも加算しない。支出合計は正の金額として返し、収支は収入から支出を差し引く。

## 合計と上限

各入力値だけでなく、残高・収入・支出の各加算直後と最終収支も検証する。途中で安全整数範囲を超えた時点で処理を中止し、後の値で相殺されても成功扱いにしない。この保守的な仕様では、同じ値の集合でも加算順によって拒否される場合がある。将来この範囲を超える金額が必要なら、BigInt等による計算とAPI表現を別途設計する。

関数は入力配列やオブジェクトを変更しない。例外文言に入力金額や個人情報を含めない。
